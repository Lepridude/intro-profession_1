## Моя рефлексия

В ходе практической работы я изучил основы Git и работу с REST API на примере сервиса OMDb, который возвращает информацию о фильмах.  
Я создал репозиторий и работал с ветками `master`, `movie-output-feature` и `env-feature`, чтобы разделять основную версию проекта и отдельные изменения.  
Ветка `movie-output-feature` была объединена с `master`, а `env-feature` оставлена отдельной, как требовалось в задании.  
Commit фиксирует изменения в истории проекта и позволяет отслеживать, что именно было изменено на каждом этапе.  
Для работы с Python я использовал виртуальное окружение `.venv`, установил зависимости из `requirements.txt` и запускал проект в PyCharm.  
Ветка `env-feature` загружает API-ключ из файла `.env` с помощью `python-dotenv`, а сам файл исключён из Git через `.gitignore`.  
Я проверил запрос к OMDb на фильме Inception и получил JSON-ответ с названием, годом, жанром, режиссёром, актёрами и рейтингом IMDb.  
JSON удобен тем, что ответ API можно разбирать как структуру данных и получать из неё отдельные значения по ключам, например `Title`, `Year` и `Director`.  
Вместо VS Code, указанного в методических материалах, я использовал PyCharm, а репозиторий разместил на GitHub, а не на GitVerse.
